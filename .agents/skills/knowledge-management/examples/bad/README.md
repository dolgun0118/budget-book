# Bad Examples (실패 및 문제 사례 저장소)

본 디렉터리는 프로젝트 진행 중 겪었던 실패한 결과물, 잘못된 기술적 판단, 버그 및 예외 발생 사례를 보관합니다.

실패 사례는 단순한 오답 노트가 아니며, AI Agent가 동일한 실수를 반복하지 않도록 하는 가장 강력한 학습 데이터입니다.

---

## 1. 아카이빙 기준

다음과 같은 상황이 발생했을 때 본 디렉터리에 기록합니다:
- 잘못된 아키텍처/라이브러리 선택으로 리팩토링이 필요했던 경우
- 특정 환경에서 발생한 심각한 버그 또는 예외 상황
- 플레이북의 절차를 누락하거나 잘못 이해하여 발생한 실패
- 요구사항을 잘못 해석하거나 비효율적인 방식으로 문제를 해결하려 했던 사례

---

## 2. 필수 기록 요소

모든 실패 사례는 [templates/example-bad-template.md](file:///C:/Users/zipo1/workspace/budget-book/.agents/skills/knowledge-management/templates/example-bad-template.md)를 준수하여 다음 내용을 포함해야 합니다:
1. **발생 상황 (Context)**: 문제 발생 당시의 환경과 시도했던 작업
2. **문제/에러 스냅샷 (Snapshot)**: 실패한 코드 패턴, 에러 메시지
3. **근본 원인 분석 (Root Cause)**: 왜 실패했는가 (단순 증상이 아닌 원인 규명)
4. **해결 방법 (Resolution)**: 문제를 극복한 구체적인 해결 과정
5. **교훈 및 재발 방지 (Lesson & Prevention)**: 향후 방지를 위해 어떤 플레이북의 금지사항/체크리스트에 반영되었는가
