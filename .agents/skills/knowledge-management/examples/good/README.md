# Good Examples (모범 사례 저장소)

본 디렉터리는 프로젝트에서 성공적으로 수행된 모범적인 결과물, 높은 완성도를 보인 구현 사례, 그리고 올바른 의사결정 사례를 보관합니다.

---

## 1. 아카이빙 기준

단순히 "에러 없이 동작했다"는 수준을 넘어, 다음 중 하나 이상을 충족하는 사례를 기록합니다:
- 코드 구조의 가독성과 확장성이 뛰어난 모범 코드
- 플레이북의 절차를 완벽히 준수하여 효율적으로 완성된 산출물
- 성능 최적화, 보안 강화, 사용자 경험 개선 측면에서 뛰어난 성과를 낸 사례
- 복잡한 문제 상황에서 올바른 트레이드오프 판단을 내린 아키텍처 결정

---

## 2. 필수 기록 요소

모든 모범 사례는 [templates/example-good-template.md](file:///C:/Users/zipo1/workspace/budget-book/.agents/skills/knowledge-management/templates/example-good-template.md)를 준수하여 다음 내용을 포함해야 합니다:
1. **맥락 (Context)**: 어떤 요구사항과 제약 아래에서 수행되었는가
2. **결과물 발췌 (Snapshot)**: 코드/설계의 핵심 모범 구문
3. **성공 요인 분석 (Success Factors)**: 왜 이것이 좋은 결과물/판단인가
4. **적용된 원칙 (Applied Principles)**: 어떤 지식/원칙이 결정적이었는가
5. **향후 권장사항 (Recommendation)**: 다음 작업 시 계승해야 할 패턴
