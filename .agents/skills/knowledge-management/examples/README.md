# Examples 디렉터리 안내

본 디렉터리는 프로젝트 진행 과정에서 발생한 실제 산출물과 의사결정 사례를 축적하는 아카이브입니다.

단순히 결과 파일만 보관하는 것이 아니라, **"왜 좋은 결과물인가(Good)"** 또는 **"왜 잘못되었고 무엇이 문제였는가(Bad)"**에 대한 심층 분석과 맥락을 함께 기록하여 AI Agent와 작업자가 향후 작업의 품질 기준점으로 활용하도록 합니다.

---

## 디렉터리 구조

- **[good/](file:///C:/Users/zipo1/workspace/budget-book/.agents/skills/knowledge-management/examples/good)**: 
  - 모범적인 결과물, 성공적인 구현 사례, 올바른 설계 판단
  - 템플릿: [templates/example-good-template.md](file:///C:/Users/zipo1/workspace/budget-book/.agents/skills/knowledge-management/templates/example-good-template.md)
- **[bad/](file:///C:/Users/zipo1/workspace/budget-book/.agents/skills/knowledge-management/examples/bad)**: 
  - 실패한 결과물, 잘못된 판단, 버그 및 장애 발생 사례, 트러블슈팅 이력
  - 템플릿: [templates/example-bad-template.md](file:///C:/Users/zipo1/workspace/budget-book/.agents/skills/knowledge-management/templates/example-bad-template.md)

---

## 활용 방법

1. **작업 수행 전 벤치마크**: 유사한 작업을 시작할 때 `good/`의 사례를 참고하여 목표 품질과 구조를 설정합니다.
2. **실수 예방**: `bad/`의 사례를 검토하여 이전에 겪었던 함정이나 잘못된 패턴을 사전에 회피합니다.
3. **결과물 검수 기준**: 플레이북의 검수 체크리스트와 함께 `examples`의 품질 수준을 대조하여 셀프 리뷰를 수행합니다.
